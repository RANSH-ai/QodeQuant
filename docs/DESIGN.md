# Design System & Guidelines

## Color Palette
- **Background (Main):** `#050505` (Deep Black)
- **Background (Panels):** `#111111`, `#1a1a1a`
- **Border:** `#222222`, `#333333`
- **Primary Accent:** Blue (`#3b82f6` / Tailwind `blue-500`)
- **Secondary Accent:** Purple (used in gradients)
- **Text (Primary):** `#ffffff` (White)
- **Text (Secondary):** `#9ca3af` (Gray-400)

## Typography
- **Primary Font:** Inter / System Sans-serif (for UI elements)
- **Code Font:** 'JetBrains Mono', 'Fira Code', monospace (for Editor and Console)

## UI Components
- **Buttons:** Subtle gradients or solid backgrounds with slight hover effects (brightness increase or border color change).
- **Icons:** Lucide React icons, strictly sized to `14px` or `16px` for a clean, professional VS Code-like look.
- **Scrollbars:** Custom slim scrollbars (`custom-scrollbar` class) to maintain a sleek aesthetic.
